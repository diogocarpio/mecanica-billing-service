# Mecanica Billing Service

Microsserviço responsável por orçamentos e pagamentos das ordens de serviço.

## Responsabilidades

- Gerar orçamentos
- Enviar orçamentos para aprovação
- Registrar e verificar pagamentos
- Atualizar o status da ordem de serviço após confirmação do pagamento
- Integrar com Mercado Pago

## Tecnologias

- Java 17
- Spring Boot 3.x
- MongoDB (NoSQL)
- RabbitMQ (mensageria)
- Docker
- Kubernetes
- Terraform
